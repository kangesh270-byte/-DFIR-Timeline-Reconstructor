# 🛡️ Interactive DFIR Incident Timeline Reconstructor

> Transforming raw cyber evidence into interactive timelines for faster, smarter, and more accurate digital forensic investigations.

---

## 📖 Overview

The **Interactive DFIR Incident Timeline Reconstructor** is a Digital Forensics and Incident Response (DFIR) platform that enables investigators to upload forensic evidence, reconstruct attack timelines, map adversary techniques using the MITRE ATT&CK Framework, analyze the Cyber Kill Chain, and generate structured investigation reports.

---

## 🚨 Problem Statement

- Evidence is scattered across multiple logs and artifacts.
- Manual timeline reconstruction is slow and error-prone.
- Existing tools provide limited evidence correlation.
- DFIR workflows are difficult for beginners.
- A unified platform is required for investigation and reporting.

---

## ✨ Features

- 📂 CSV & JSON Evidence Upload
- 📅 Timeline Reconstruction
- 🎯 MITRE ATT&CK Mapping
- 🔗 Cyber Kill Chain Analysis
- 📊 Incident Scoring
- 📑 Investigation Report Generation
- 🔍 Evidence Correlation
- 🔐 Secure Authentication
